# Context
Amateur-grade Halloween display set up outside. Extensive use of props, lighting, and practical FX to create a haunted walk-through for visitors. This project is specifically related to controlling the entire display.

# Projects
Currently, only one large-scale dmx project is being planned: a custom-made volcano. It is about 10ft tall made from a wooden frame. In the core there are three devices from the company Moka. We have a fogger with lights, a CO2 cannon, and a LPG flame thrower to control. Around and inside the volcano will be LEDs to curate the mood of the display. We assume we will be controlling at least 8 LEDs.
