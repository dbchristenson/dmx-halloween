Your show, step by step

The console follows the live show. The stage diagram shows fixture positions from above; light beams and effects reflect the output frame.

Run the show

  1. Check the mode below the title. Simulation uses a fake DMX driver. Live DMX controls connected fixtures.
  2. Watch the phase: dormant → active → imminent → eruption. Request eruption starts the 30-second warning first and respects cooldown.
  3. Hold dormant returns an active show to dormant and keeps it there. A warning or eruption finishes first. If timing is paused, resume timing for hold to take effect. Release hold to resume the cycle.
  4. Pause timing freezes safe phases. During imminent or eruption, the pause waits until dormant.

Test lights and effects

Wait for dormant, then enter test mode. It holds the show while you toggle lights, set fog output, or request a timed burst. Exit test mode clears overrides; release hold separately to resume.

Understand pyro status

Flame and CO₂ require software arming and the physical arm switch. Rehearsal configuration prevents software arming. Burst duration limits and gaps still apply. Disarm pyro turns off software arming.

Sounds and simulation

Tap an audio filename to preview it on the show speaker. Import adds files to the audio library; assign them in [audio] in config/show.toml and restart the app. Simulation speed changes the show clock and is only available with the fake driver.

CO₂ tank

The meter estimates the remaining supply. Reset it only after physically connecting a fresh tank.

Make yourself comfortable

Use the moon button to switch between light and dark themes. Your choice is saved on this device. Close this guide with the × button or Escape.
